# نظام تسجيل الدخول - SkylineWeb CMS

## نظرة عامة
تم إنشاء نظام تسجيل دخول متكامل مع إدارة صلاحيات للمستخدمين في لوحة تحكم SkylineWeb CMS.

## المميزات

### 🔐 نظام تسجيل الدخول
- واجهة تسجيل دخول جميلة ومتجاوبة
- دعم اللغة العربية والاتجاه RTL
- إظهار/إخفاء كلمة المرور
- خيار "تذكرني" للجلسات الدائمة
- رسائل خطأ واضحة
- حالة التحميل أثناء تسجيل الدخول

### 👥 إدارة المستخدمين
- نوعين من المستخدمين:
  - **مدير (Admin)**: صلاحيات كاملة
  - **مستخدم (User)**: صلاحيات محدودة
- كل مستخدم له كلمة مرور خاصة به

### 🛡️ نظام الصلاحيات
- **المدير**: يمكنه الوصول لجميع الأقسام
  - لوحة التحكم الرئيسية
  - إدارة المستخدمين
  - إدارة الصفحات
  - التحليلات
  - التقويم
  - المدفوعات
  - الإعدادات

- **المستخدم العادي**: صلاحيات محدودة
  - لوحة التحكم الرئيسية
  - إدارة الصفحات
  - التقويم

### 💾 إدارة الجلسات
- حفظ الجلسات في localStorage (لخيار "تذكرني")
- حفظ الجلسات في sessionStorage (للجلسات المؤقتة)
- التحقق التلقائي من الجلسات الموجودة
- تسجيل الخروج الآمن

## بيانات المستخدمين التجريبية

### المدير
- **اسم المستخدم**: `admin`
- **كلمة المرور**: `admin123`
- **الصلاحيات**: جميع الصلاحيات

### المستخدم العادي
- **اسم المستخدم**: `user`
- **كلمة المرور**: `user123`
- **الصلاحيات**: محدودة

## الملفات المضافة

صفحة تسجيل الدخول الرئيسية مع:
- نموذج تسجيل الدخول
- بيانات تجريبية معروضة
- رسائل خطأ

- وظائف مساعدة

### 4. `test-login.html`

- اختبار بيانات المستخدمين
- اختبار تسجيل الدخول

- اختبار الصلاحيات
- اختبار تسجيل الخروج

## كيفية الاستخدام

### 1. تسجيل الدخول
1. افتح `login.html`
2. أدخل اسم المستخدم وكلمة المرور
3. اختر "تذكرني" إذا أردت جلسة دائمة
4. اضغط "تسجيل الدخول"

### 2. التنقل في لوحة التحكم
- سيتم إخفاء الأقسام التي لا تملك صلاحية للوصول إليها
- يمكنك الوصول فقط للأقسام المسموح لك بها

### 3. تسجيل الخروج
- اضغط على اسم المستخدم في الأعلى
- اختر "تسجيل الخروج" من القائمة المنسدلة

## الأمان

### الميزات الأمنية
- التحقق من الصلاحيات في كل قسم
- إدارة آمنة للجلسات
- مسح الجلسات عند تسجيل الخروج
- حماية من الوصول غير المصرح به

### ملاحظات الأمان
- هذا نظام تجريبي للعرض فقط
- في الإنتاج، يجب استخدام:
  - تشفير كلمات المرور
  - HTTPS
  - خادم خلفي للتحقق
  - قاعدة بيانات آمنة
