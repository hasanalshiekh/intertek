# SkylineWeb CMS Dashboard

## نظرة سريعة

داش بورد CMS كامل ومتطور لـ SkylineWeb مع واجهة عربية حديثة.

## الملفات المطلوبة

- `dashboard.html` - الملف الرئيسي للداش بورد
- `dashboard.css` - ملف التصميم والأنماط
- `dashboard.js` - ملف الوظائف والتفاعل
- `start-dashboard.bat` - ملف تشغيل على Windows
- `start-dashboard.sh` - ملف تشغيل على Linux/Mac
- `README_DASHBOARD.md` - دليل مفصل للداش بورد

## كيفية التشغيل

### على Windows
```
start-dashboard.bat
```

### على Linux/Mac
```bash
chmod +x start-dashboard.sh
./start-dashboard.sh
```

### تشغيل يدوي
افتح ملف `dashboard.html` في المتصفح
