# SkylineWeb CMS Dashboard

## نظرة عامة

هذا هو داش بورد CMS كامل ومتطور لـ SkylineWeb، مصمم بتقنيات حديثة وواجهة مستخدم عربية سهلة الاستخدام.

## المميزات الرئيسية

### 🎨 التصميم والواجهة
- **ثيمات متعددة**: دعم الوضع الفاتح والداكن
- **تصميم متجاوب**: يعمل على جميع الأجهزة والشاشات
- **واجهة عربية**: تصميم مخصص للغة العربية مع دعم RTL
- **ألوان حديثة**: ألوان متناسقة ومناسبة للمشروع

### 📊 لوحة التحكم الرئيسية
- **إحصائيات حية**: عرض KPIs مهمة (المستخدمين، الإيرادات، المشاهدات، النمو)
- **رسوم بيانية تفاعلية**: مخططات خطية ودائرية للبيانات
- **وضع العرض التجريبي**: زر تبديل لإظهار بيانات تجريبية
- **النشاطات الحديثة**: قائمة بالنشاطات الأخيرة

### 👥 إدارة المستخدمين
- **قائمة المستخدمين**: عرض جميع المستخدمين مع تفاصيلهم
- **إضافة مستخدمين**: نموذج لإضافة مستخدمين جدد
- **تعديل وحذف**: إمكانية تعديل وحذف المستخدمين
- **تصفية وبحث**: البحث في المستخدمين وتصفيتهم حسب الدور

### 📄 إدارة الصفحات
- **عرض الصفحات**: عرض جميع صفحات الموقع
- **حالة الصفحات**: عرض حالة كل صفحة (منشور/مسودة)
- **إحصائيات المشاهدات**: عدد مشاهدات كل صفحة
- **تعديل وعرض**: إمكانية تعديل وعرض الصفحات

### 📈 التحليلات
- **مخططات متقدمة**: رسوم بيانية للزيارات ومصادر الزيارات
- **فترات زمنية**: اختيار فترات زمنية مختلفة للتحليل
- **بيانات تفاعلية**: تحديث البيانات في الوقت الفعلي

### 📅 التقويم
- **تقويم شهري**: عرض الأحداث والمواعيد
- **إضافة أحداث**: إمكانية إضافة أحداث جديدة
- **تنقل بين الشهور**: التنقل بين الشهور المختلفة
- **تمييز اليوم الحالي**: تمييز اليوم الحالي في التقويم

### 💳 المدفوعات
- **نظرة عامة**: إحصائيات المدفوعات (إجمالي، معلق، مكتمل)
- **قائمة المدفوعات**: عرض جميع المعاملات
- **حالات الدفع**: تتبع حالات الدفع المختلفة
- **معالجة المدفوعات**: إمكانية معالجة المدفوعات المعلقة

### ⚙️ الإعدادات
- **إعدادات الموقع**: تعديل اسم ووصف الموقع
- **إعدادات المستخدم**: تعديل معلومات المستخدم الشخصية
- **حفظ التغييرات**: حفظ جميع التغييرات

### 🤖 المساعد الذكي (AI Chatbot)
- **محادثة تفاعلية**: محادثة مع المساعد الذكي
- **ردود ذكية**: ردود ذكية ومفيدة
- **ربط WhatsApp**: إرسال الرسائل إلى WhatsApp
- **واجهة سهلة**: واجهة محادثة سهلة الاستخدام

## كيفية التشغيل

### المتطلبات
- متصفح ويب حديث (Chrome, Firefox, Safari, Edge)
- اتصال بالإنترنت (لتحميل الخطوط والأيقونات)

### خطوات التشغيل
1. **تحميل الملفات**:
   ```
   dashboard.html
   dashboard.css
   dashboard.js
   ```

2. **فتح الداش بورد**:
   - افتح ملف `dashboard.html` في المتصفح
   - أو استخدم خادم محلي لتشغيل الملفات

3. **الاستخدام**:
   - استخدم القائمة الجانبية للتنقل بين الأقسام
   - جرب تبديل الثيمات (فاتح/داكن)
   - فعّل الوضع التجريبي لرؤية البيانات التجريبية
   - جرب المساعد الذكي

## التخصيص

### الألوان
يمكن تخصيص الألوان من خلال تعديل متغيرات CSS في ملف `dashboard.css`:

```css
:root {
    --primary-color: #0ea5e9;
    --secondary-color: #22c55e;
    --warning-color: #f59e0b;
    --danger-color: #ef4444;
    /* ... المزيد من الألوان */
}
```

### البيانات
يمكن تخصيص البيانات من خلال تعديل المصفوفات في ملف `dashboard.js`:

```javascript
// بيانات المستخدمين
const usersData = [
    { name: 'اسم المستخدم', email: 'email@example.com', role: 'الدور', status: 'الحالة', date: 'التاريخ' }
];

// بيانات الصفحات
const pagesData = [
    { title: 'عنوان الصفحة', status: 'الحالة', views: 0, date: 'التاريخ' }
];
```
